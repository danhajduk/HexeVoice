# Manrope

This directory contains the unmodified Manrope variable TrueType font for the
Waveshare P4 7-inch Hexe UI.

- Font: `Manrope-VariableFont_wght.ttf`
- Weight axis: 200 through 800
- Source: `https://github.com/google/fonts/tree/main/ofl/manrope`
- Retrieved: 2026-09-16
- Copyright: Copyright 2018 The Manrope Project Authors
- License: SIL Open Font License 1.1; see `OFL.txt`

Keep `OFL.txt` with redistributed copies of the font. Keep `FONTLOG.txt` with
the font and any derivative work, as requested by the upstream font log.

The current P4 firmware renderer does not load this TTF yet. Do not add the
font to the board delivery manifest until the asset pipeline and endpoint
storage contract support a validated `font` media type.
